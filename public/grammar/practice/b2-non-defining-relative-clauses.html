Practise Non-defining relative clauses

Let’s see how this pattern works in a couple of new situations. Check each answer when you’re ready.

First try

We missed the last bus, ___ was frustrating.

Try a different example

Our coach, ___ bike was stolen, took the bus.

Write it yourself

Compare with the model answer

Mei, who teaches art, showed me the studio. The commas set off the extra information.
