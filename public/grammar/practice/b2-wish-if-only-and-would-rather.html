Practise Wish, if only and would rather

Let’s see how this pattern works in a couple of new situations. Check each answer when you’re ready.

First try

I missed the train yesterday. “If only I ___ earlier!”

Try a different example

I want someone else to call later. “I’d rather you ___ tomorrow.”

Write it yourself

Compare with the model answer

I wish I’d brought my umbrella. Use the past perfect for a regret about an earlier choice.
