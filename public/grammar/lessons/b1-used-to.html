B1 grammar

Used to

Use used to plus the base verb for past habits or states that have changed. In a question with did, write use to.

The pattern

used to + base verb; did/didn’t + use to + base verb

Work through an example

  1. As a child, you ate cereal every morning. Now you rarely do.
  2. Choose used to because it was a habit that changed.
  3. Say “I used to eat cereal every morning.”

More examples

I used to hate mornings. Did you use to get up this early?

  • They used to live above a shop.
  • We didn’t use to have a car.
  • Did you use to play chess?
  • There used to be a tree here.

What to watch for

  • For a single event, use the past simple: “I fell off my bike on Monday.”
  • “I’m used to cycling” means cycling feels normal to me now. Here to is followed by -ing.

Your turn

Fix “Did she used to work here?”

Reveal the answer

Did she use to work here? After did, use use without d.
