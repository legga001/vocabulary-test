A2 grammar

Joining ideas

Use because for a reason, so for a result and but for a contrast.

Let’s talk it through

Mr Fox says Draw a tiny arrow from cause to result. Because points back to the reason. So moves forward to what happened as a result. But takes the conversation in a different direction.

The pattern

because introduces a reason; so introduces a result; but joins contrasting ideas

How does it work?

  1. You missed the bus and arrived late.
  2. Give the reason: “I arrived late because I missed the bus.”
  3. Put the events in order with so: “I missed the bus, so I arrived late.”

More examples

We stayed inside because it rained. It rained, so we stayed inside.

  • We left because it was cold.
  • The café was closed, so we went home.
  • I like apples, but I don’t like pears.
  • Because the path was icy, we turned back.

What to watch for

  • When the because part comes first, a comma often marks where the main idea begins.
  • Use because of before a noun: “The game stopped because of rain.”
  • In a simple sentence, choose one link: “Because I was tired, I left.”
