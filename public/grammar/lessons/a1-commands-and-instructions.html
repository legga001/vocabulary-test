A1 grammar

Commands and instructions

Start with the base verb for a command. Use don’t plus the base verb to tell someone to avoid an action.

Let’s talk it through

Mr Fox says When you give directions, you can go straight to the action. Add please if you want to make the instruction sound gentler.

The pattern

base verb to give a direction; don’t + base verb to stop an action

How does it work?

1. Make a negative instruction

  1. A friend is about to touch a wet painting.
  2. Start with don’t, then add touch.
  3. Say “Don’t touch the painting.”

2. Tell someone what to do

Start with the base verb open → “Open the window, please.”

3. Make a suggestion to do something together

Put let’s before start → “Let’s start now.”

More examples

Turn left at the café. Don’t cross the road yet.

  • Please take a seat.
  • Open the box carefully.
  • Be quiet, please.
  • Don’t forget your umbrella.

What to watch for

  • The listener is usually clear, so you can leave out you.
  • For an offer of help, “Let’s carry it together” includes the speaker.
