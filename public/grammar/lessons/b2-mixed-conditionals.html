B2 grammar

Mixed conditionals

Mix the time frames when the condition and result belong to different times. A past change can have an imagined result now.

Let’s talk it through

Mr Fox says Put a time label on each half: past or now. The two time labels can be different. For instance, a decision you made yesterday might still affect how you feel today.

The pattern

past cause, present result: if + had + participle, would + base verb; present state, past result: if + past form, would have + participle

How does it work?

  1. You lost your map earlier. Now you’re lost.
  2. Use had kept for the imagined past: “If I’d kept the map”.
  3. Use would know for the imagined present: “I’d know where we are now.”

More examples

If I’d charged my phone last night, I’d have a working map now.

  • If I’d caught the early train, I’d be home now.
  • If I weren’t afraid of heights, I’d have climbed the tower yesterday.
  • If we’d brought coats, we wouldn’t be freezing.

What to watch for

  • Use time words like now and yesterday to make the mix easy to follow.
  • If both events are in the past, use the third conditional for both parts.
